# Oracles: they write and check test files from the formats' specs, apart from the readers and
# the writer, so a wrong ID in Metadata fails a test instead of agreeing with itself.
oracle Sources/Tools/Fixtures | the fixture generator writes every tag format from its spec, independent of Metadata and TagWriter
oracle Sources/Tools/TagCorpus | its independent readers and round-trip checks re-read tags apart from Metadata, as a test does

# Code with the same shape and nothing to share.
block Sources/Core/Library/SmartRules.swift Sources/Core/Settings/TrackTableLayout.swift Sources/Core/Settings/VisitLog.swift | each strict Codable type's memberwise init, CodingKeys and rejectUnknownKeys decoder; the fields differ, so only the shape repeats
